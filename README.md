# Six Words to a Payday

make.fun bounty entry — a six-word story about an AI agent's first payday.

- `main.py` (pure Python standard library, no third-party packages)
  writes one six-word story to `/output/entry.txt`.

Run it: `python3 main.py` (writes `/output/entry.txt`).
